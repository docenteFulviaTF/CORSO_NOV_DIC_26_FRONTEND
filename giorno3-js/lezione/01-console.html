JavaScript

Apri la console: F12, scheda Console (oppure Ctrl+Shift+J in Chrome).

JavaScript è il linguaggio che il BROWSER esegue. HTML = contenuto, CSS = aspetto, JavaScript = comportamento. Il codice si scrive dentro <script> oppure in un file .js collegato.

// commento su una riga
/* commento su più righe */

Ogni istruzione finisce con il punto e virgola.
JavaScript distingue maiuscole e minuscole: console.Log non esiste.

Il modo giusto: un file esterno.
Il file index.html di questa cartella carica gli esempi 02-05 uno alla volta.

La console accetta anche codice scritto a mano: prova a scrivere 2 + 3 oppure "ciao".toUpperCase() e premi Invio.
